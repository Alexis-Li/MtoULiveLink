# MtoU_LiveLink

[English](README.md)

MtoU_LiveLink 连接同一台电脑上的 Maya 与 Unreal Editor，让你在 Maya 中制作时，
直接在 Unreal 中查看角色动画、BlendShape 和服装修改效果。支持实时预览与动画
缓存播放，可在 Maya 中跟随 Level Sequence 的镜头与时间，在主角色旁加入一个
骨骼副对象，不会创建动画或预览资产。

## 兼容性

- 64 位 Windows
- Autodesk Maya 2024
- 官方原版 Unreal Editor 5.7.4
- 仅用于编辑器，不支持 PIE（Play In Editor）。

不保证兼容修改版或第三方 Unreal Engine 5.7。Maya 与 Unreal 组件应使用同一版本。

## 安装

从仓库的 Releases 页面下载同一版本的两个压缩包：`MtoULiveLink-<版本>.zip`
（Maya）和 `MtoULiveLink-<版本>-UE5.7.zip`（Unreal 源码插件）。以下组件路径
均相对于本仓库根目录，与压缩包内容一致。

**Maya**

1. 把 Maya 组件文件夹（`maya/MtoULiveLink/`，或 `MtoULiveLink-<版本>.zip`
   解压后的文件夹）放在一个长期保留的位置。
2. 打开 Maya，把文件夹中的 `install.mel` 拖入视口。
3. 在提示中确认。工具架上会出现 **MtoU** 按钮（已有按钮会沿用），点击即可打开。

安装会把这个文件夹登记为 Maya 模块（用户 Maya 目录 `modules` 文件夹中的
`MtoULiveLink.mod`，用户 Maya 目录通常是 `文档/maya`），之后不要移动或删除
该文件夹。文件夹路径包含中文等非英文字符时，Maya 无法从该路径加载，安装会把
工具复制到 `modules/MtoULiveLink`，原文件夹之后可以删除。发现不是用 `install.mel`
装上的旧版本（例如 Maya scripts 目录中的 `MtoULiveLink.py`）时，安装会列出
它们并询问，确认后删除，取消则不做任何修改。当前 Maya 已打开过旧版本时，
按提示重启 Maya。

**Unreal**

1. 将 `unreal/MtoULiveLink/`（或 Unreal 压缩包中的 `MtoULiveLink` 文件夹）复制到
   `<Project>/Plugins/MtoULiveLink/`。
2. 编译 Unreal 项目。
3. 启用 **Live Link** 和 **MtoU_LiveLink**，然后重启 Unreal Editor。

**升级、回退与卸载**

Maya 与 Unreal 组件成对升级和回退。协议 v12 的开发快照也须使用同一构建的两端：
相同协议号不代表这些未发布快照互通。缺少必需身份字段时会停止协商，并提示更新
双端。先结束当前会话，然后：

- 升级：把新版 Maya 组件的 `install.mel` 拖入 Maya，替换 Unreal 插件，
  再重新连接。每个场景首次使用新版面板时，请在 **连接** 页设置角色和所需的副对象。
  旧版的 Follow Scene（跟随场景）传输上限会转为 **60** 帧／秒。
- 回退：拖入上一版本 Maya 组件的 `install.mel`。上一版本没有 `install.mel`
  时，先删除下方卸载列出的文件，再按该版本的说明安装。最后恢复上一版本的
  Unreal 插件构建并重新连接。
- 卸载 Maya 组件：删除用户 Maya 目录 `modules` 中的 `MtoULiveLink.mod` 和
  `MtoULiveLink` 文件夹（如有），删除工具架上的 MtoU 按钮，然后重启 Maya。

## 准备角色

- Maya 必须包含启用网格实际蒙皮所需的骨骼及完整祖先链，包括骨骼之间的中间
  分组，名称与父子关系应一致。同一短名出现在多个 Maya 分支时，支持同一父级下
  的 Unreal 导入数字后缀或 32 位 hash 后缀，并报告映射。无关的导出骨骼分支
  不会阻止连接；但每根 Unreal 骨骼只由一根 Maya 骨骼驱动，若同一父级下有两根
  Maya 骨骼发布同一名称，请在 Maya 中重命名其中一根。
- 选中变形根骨骼，在 **连接** 页点击 **设置角色**。Display 控制器可选。
  衣服是当前可见、蒙在
  该骨骼上的网格集合。自身、祖先、LOD 可见性或可见性覆盖隐藏的网格不参与
  BlendShape；可见的 Template 和 Reference 网格参与。唯一可识别的 Display 枚举
  沿用原有衣服标签，否则按排序后的网格名显示。“选择 Display 控制器”仅用于
  可选标签，不决定参与网格。
- 预览服装时，准备与 Primary Driver 服装位置对齐的 **Preview Static Mesh**。
  服装与身体等非服装几何体应使用不同的导入材质槽。
- 预览 BlendShape 时，Maya BlendShape 与 Unreal Morph Target 需要名称匹配。
  **动画** 始终传递 BlendShape。使用 **模型** 时，在 Maya 的 **连接** 页开启 **传递 BS**。

### 拆分角色部件

当同一个角色由多个 Skeletal Mesh 组成时，将服装数据来源指定为 Primary Driver，
其余网格添加到 Binding 的 **Additional Parts**。所有启用部件在同一个连接下摆姿和显示：

- 只有 Primary Driver 提供服装识别、权重转移和 **Preview Morph transfer**。
- 每个部件包含名称、Skeletal Mesh 和 **Enabled** 开关。所有网格必须共用同一个
  **Skeleton** 资产。各 LOD 实际蒙皮所需的共有骨骼及其完整祖先链，必须具有一致
  的层级和参考姿势。部件独有的次级骨骼即使不在 Primary 中，也会接收 Maya 动画；
  禁用部件不增加骨骼依赖。
- 新增服装及次级骨骼后，导入新服装、更新启用部件；已连接时会为同一角色与目标
  自动重新协商。旧网格仅在自身绑定姿势或权重改变时需要更新。Maya 缺少必要骨骼或共有骨骼不兼容时仍会拒绝连接，
  并提示具体部件和骨骼。
- 只有某个部件拥有的 Morph Target 也会传输；多个部件同名的 Morph 会接收到
  相同数值。
- 新增、删除、启用、停用或替换部件会结束旧会话，并为同一角色与目标自动发起
  新协商。已生成的服装预览会保留；Primary Driver、Preview Static Mesh、
  **Driver Garment Slot Override** 或相关导入数据变更后需要 **Refresh Preview**。
- 重命名部件或调整列表顺序无需重连。

## 首次连接

1. 在 Unreal 中创建 **MtoU_LiveLink Binding** 资产，指定
   **Primary Driver Skeletal Mesh**，并按需添加 **Additional Parts**。
2. 将 Binding 资产从内容浏览器拖入关卡，创建对应的 Binding Actor。
   细节面板默认展开 **MtoU · 运行状态**（分别显示预览与连接状态及下一步）、
   **角色组成**（主体和可展开的附加部件）和 **预览控制**（绑定资产、生成的网格、
   刷新、删除及缓存播放）。需要查看或选中完整诊断时，展开 **高级设置与诊断**；
   **复制完整诊断** 会复制包括镜头联动详情在内的全部内容，便于报告问题。
   没有诊断时日常界面不会显示空白日志。
   连接状态在首次连接前显示“未连接”，流式连接中显示“已连接”，输入变化协商期间
   显示“正在重新连接”，停止后显示“连接已中断”；查看原因后在 Maya 明确“连接”。
3. 在 Maya 点击工具架上的 **MtoU** 按钮。选中变形根骨骼，在 **连接** 页点击
   **设置角色**。要换根骨骼时点 **重设**。这一页可以看角色、服装、根骨骼路径、
   骨骼、BlendShape 和服装网格数量，也可以 **选择 Display 控制器**、在提示有重名时
   **选中重名骨骼**，以及设置或移除副对象。名称和路径太长时，悬停可看全文。
4. 工作流选 **动画**，点顶部的 **连接**。在 Maya 摆姿、拖动时间轴或播放动画，
   就能在 Unreal 里看到效果。

**连接**、**预览**、**相机**、**诊断** 四页共用顶部状态区。这里显示连接状态、谁控制
时间、当前角色和服装，以及场景帧率或当前帧。实时预览时，M（Maya）和 U（Unreal）
之间显示最近一秒实际发送的帧数。缓存播放和联动时，分别会显示 **UE 播放** 和
**UE 控制时间**。任一页都可以在顶部 **连接** 或 **断开**。按钮不可用时，悬停可看原因。

### 按场景记住设置

Maya 会记住工作流、**传递 BS**、**出错时弹窗提示**、传输上限、捕获范围和起止帧，
以及主角色和副对象的根骨骼与选定的 Display 控制器。这些设置按场景文件路径存放在
Maya 用户偏好里，场景文件本身不会被修改。未命名场景的设置只在本次打开面板期间
生效，首次保存或另存为会把当前设置带到新路径。打开场景、重开面板或重启 Maya 时
会恢复并检查设置。更新引用后，如果原路径找不到了，请在 **诊断** 页查看提示，再重设
对应的根骨骼或 Display 控制器。

### 诊断与性能

打开 **诊断** 页，**最近一次操作** 会显示当前结果。出错时可查看错误码、完整说明
和可用的恢复方法。
BlendShape 差异、骨骼名称映射等仍可从 **此前的连接差异** 查阅。点击 **完整诊断**
会打开可调整大小的窗口，顶部显示同一个最新结果，下方可查看连接、角色、性能、
相机和联动详情。窗口开着也会随新结果刷新。长信息可滚动查看，选中文字后按 Ctrl+C
复制。**出错时弹窗提示** 控制连接警告、连接失败和意外断开的弹窗。同一连接的相同
警告只提示一次，结果都会记入 **诊断**。

实时预览会在姿势变化时发送新姿势，角色静止时会跳过重复的姿势。**性能** 会显示
**Maya 采样** 和 **UE 应用** 的实测耗时，并与场景的每帧时间预算比较。下方还会显示
实际发送频率、等待发送时被更新姿势替换的帧数，以及 UE 编辑器帧率。没有读数时
显示“—”，例如兼容的旧版 UE 组件没有回传性能数据。**完整诊断** 会列出两端的宿主、
实际加载的插件和协议版本。对端未提供的宿主或版本项也显示“—”。

Unreal Binding Actor 的 **高级设置与诊断** 中，**实时预览性能** 还会显示解析、
重定向和应用耗时、新姿势完成显示骨骼更新的实际频率，以及其编辑器帧率。需要报告
问题时，可在连接期间用 Unreal 的 **复制完整诊断** 保存读数。

连接期间，Unreal 会在后台保持更新，包括 Maya 位于前台时。运行状态会显示
**连接期间 UE 在后台保持更新**。断开后恢复原有后台降频与视口实时行为，
**Use Less CPU when in Background** 偏好及视口 Realtime 设置保持原值。
编辑器最小化时不会绘制视口。

## 连接期间的修改

同一 Maya 角色与 Unreal 目标保持不变时，修改可见服装网格集合、“动画／模型”、
“传递 BS”或 **Additional Parts** 会结束旧会话，按最新输入自动重新协商。
撤销／重做以及相关 Driver 或 Preview 输入／重导入变化也遵循此规则。旧缓存会
清除，镜头联动资源会恢复；新会话成功后返回实时预览，需要联动时请重新进入。
仅标签改名、部件排序、可见集合不变的 Template／Reference 样式变化，以及服装
比较均保持当前会话。

两端显示“正在重新连接”，重复“连接”不可用，“断开”可取消。可用差异与失败写入
状态和诊断，不弹出 Maya 确认对话框。旧会话准备最多 5 秒，整个自动操作最多
32 秒，持续编辑不会延长期限；失败或超时后停止，不重试。

参与主体必须保持为同一实例。Maya 设置另一角色、删除或卸载根骨骼、打开或新建
场景、关闭面板，Unreal 更换或移除 Source、切换或关闭关卡、删除或替换参与的
Actor、更换其 Binding 实例，或更改配对，都会停止连接。同名重建不会恢复连接。
手动断开、网络断线、协商拒绝和资源恢复失败也会停止；之后编辑不会自行连接。
在仍存在的 Maya 面板、Unreal Source 或 Actor Details 查看原因，修正输入后明确
点击“连接”。Unreal 重启后同样需要明确连接。

模型预览在 Primary Driver、Preview Static Mesh、**Driver Garment Slot Override**
或相关导入数据改变后，仍须显式 **Refresh Preview**。预览未就绪时自动协商停止，
不会代为刷新。显式刷新也会结束流，完成后须点击“连接”；动画预览不依赖服装
预览就绪。

## 动画预览

使用 **动画** 工作流实时预览角色。在 Maya 的 **预览** 页选择 **实时**，可把
**传输上限** 设为 15、20、24、30 或 60 帧／秒。播放时取上限和场景帧率中较低的值。

需要检查一段动画时，在同一页切到 **缓存播放**。**捕获范围** 可选 **播放范围**，
使用 Maya 当前的播放区间，也可选 **自定义**，输入整数起止帧。点击 **捕获并上传**，
等待出现“缓存已就绪”。捕获时可以点 **取消捕获**。范围包括两个端点，场景帧率在
捕获开始时固定，Maya 的播放范围不受影响。支持单帧及负数起始帧。

在 UE Binding Actor 的“预览控制”中查看源帧范围、帧率、当前已应用源帧及状态。
点击“播放”从首帧开始，停止或播放结束后点击“再次播放”可回放保留的缓存。
“暂停”保留当前姿势与缓存，等待任意时长后点击“继续”从同一姿势接着播放，
不会补发暂停期间的帧。“停止”结束本次播放并保留缓存与最后姿势。需要检查某一帧
时，在“定位”旁的输入框填写整数 Maya 源帧后点击“定位”：UE 显示该帧并进入暂停。
输入格式无效或超出整数范围时，该行会提示错误。
只有本次捕获采样过的帧可用，未采样的帧会被拒绝，该行会给出请求帧与可用的源帧
范围。开启“循环”后，最后一帧播放完会回到首帧并显示当前轮次；关闭后完成当前轮。
定位与循环都复用已上传的缓存。自然结束停在最后一帧。在 Maya 再次点击“捕获并
上传”可准备新范围，旧 UE 播放会在采样前结束。在 Maya 的 **预览** 页切回 **实时**
会清除 UE 缓存并恢复实时姿势。断线重连后，若仍保留兼容的完整本地缓存，可切到
**缓存播放** 并点击 **上传保留缓存**。Maya **预览** 页的缓存状态会显示捕获、上传、
就绪、播放、暂停、定位、循环、停止和失败。经过定位或循环轮次后结束的播放会
显示为播放段完成。

单次捕获上限为 20,000 帧或 1 GiB，达到上限时请缩短范围。无效范围会在采样前
报错。采样或上传失败会返回实时预览并显示原因；回放失败时 UE 仍保留完整缓存，
可再次播放。

## 镜头联动预览

用这条工作流在 UE 的镜头与时间轴下检查 Maya 动画。它是可选的：不进入联动时，
实时预览、缓存播放和服装比较照常工作。

1. 在 Unreal 选中 Binding Actor，在 **镜头联动** 中点击 **配对为主角色**（该行
   随后显示“已配对为主角色”），并打开要跟随的 Level Sequence。
2. 在 Maya 照常连接角色，打开 **相机** 页，在 **Sequence 联动** 中点击 **开始联动**，
   也可以在 Unreal 详情面板点击 **进入联动**。Maya 会暂停自身播放，跟随 Unreal
   算出的相机姿势和 Sequence 时间，并回传角色的完整姿势。联动期间，Maya 顶部和
   **相机** 页都会显示 **UE 控制时间**。
3. 在 Maya 的 **相机** 页或 Unreal 的 **镜头联动** 中查看联动状态。Maya 跟不上时
   会显示“Maya 跟不上”和滞后时间。可暂停 Sequencer 等待 Maya 追上，或关闭占用
   性能的程序。经常出现时见[常见问题](#常见问题)。Unreal 无法完整显示某个姿势时，
   Maya 会显示“应用失败”并重试。如果持续失败，打开 Maya 的 **诊断** >
   **完整诊断** 查看原因。Unreal 的 **高级设置与诊断** 也有联动读数，可用
   **复制完整诊断** 复制整份报告。
4. **返回实时** 会恢复 Maya 的时间轴、视图和相机画幅，并保持 Maya 暂停，Unreal
   继续接管目标。需要时可在 Maya 自行恢复播放。要把原来的动画轨道交还给 Sequencer，
   点击 Maya 的 **结束联动** 或 Unreal 的 **结束预览**。**返回实时** 后仍可操作，
   直到交还完成。

**UE 相机** 区域预留了相机清单、**更新相机** 和 **从文件导入相机…** 的位置。
相机导入和更新、当前关卡和子关卡、替身信息，以及让 Maya 控制 Sequence 时间的功能
尚未开放。当前可用 **开始联动** 跟随 Unreal 的相机和时间。

联动期间，改动相机、暂停、切镜头或手动跳转都会取消旧目标。相机随时间连续运动时，
已在回传的结果会继续完成。无法安全接管目标轨道时，Unreal 会提示原因。缓存播放
期间，Maya 的 **开始联动** 和 Unreal 的 **进入联动** 都不可用。在 Maya **预览**
页选择 **实时**，等 Unreal 确认清除缓存后即可联动。恢复失败时，Maya 显示“恢复
失败”，Unreal 显示“恢复未完成”。打开 Maya 的 **诊断** > **完整诊断** 或 Unreal 的
**高级设置与诊断**，按记录恢复对应项目，例如在 Maya 解锁相机或重设时间范围，
在 Sequencer 检查对应轨道，也可重新打开关卡。如果 Unreal 再次发起联动时 Maya
无法恢复上一次的状态，连接会断开。请先按 **完整诊断** 的提示处理，再重新连接。

关闭或切换 Level Sequence、关闭其关卡或删除已配对的 Actor 都会结束联动：Unreal 交还 writer，
Maya 恢复自身状态。在 Maya 打开或新建
其他场景时，联动会先恢复开始时的场景，再断开连接。若联动驱动的 Maya 相机在联动
期间被删除或其相机 shape 被替换，Maya 会拒绝后续目标且不写入其他相机；结束预览
后重新进入联动即可使用当前相机。

## 副对象

在实时预览和镜头联动中，把一个独立的骨骼道具或第二个角色与主角色一起预览。
不设置副对象时，以上各工作流保持不变。

1. 为副对象放置第二个 Binding Actor，位置和旋转与主角色的 Binding Actor 完全
   相同；副对象自身的摆放来自它在 Maya 中的根骨骼。在它的详情面板 **镜头联动**
   中点击 **配对为副对象**。主角色的 Actor 需要用 **配对为主角色** 配对。
2. 在 Maya 选中副对象的根骨骼，在 **连接** 页的 **副对象** 区域点击 **设为副对象**。
   要提供服装标签时，可以同时选中它的 Display 控制器。
3. 照常连接。Unreal 以同一个 Maya 时间显示两个对象；镜头联动中，只有两个对象的
   全部显示都拿到新姿势时才一起显示。
4. 只想继续预览主角色时，在 Maya 的 **连接** 页或副对象 Actor 的详情面板点击
   **移除副对象**。
   Unreal 把副对象的轨道交还给 Sequence，副对象 Actor 不再跟随 Maya；主角色继续
   预览，不需要重新连接。

更换副对象、更换任一 Actor 的 Binding 实例、对已连接集合中的 Actor 重新配对
或解除配对，或删除已配对的 Actor，都会停止连接，需要明确连接。同一对象上的
输入变化会结束旧集合，并可自动协商新的实时会话，见[连接期间的修改](#连接期间的修改)。
关卡中的其他 Binding Actor 不跟随 Maya。副对象 Actor 放在其他位置或在联动中被移动时，会以“副对象
与主角色在 UE 中的放置不一致”拒绝。缓存播放和模型工作流只支持单个角色，请先移除
副对象。若移除副对象时无法恢复它的轨道，连接会结束，两端都会说明需要手动恢复的
内容。

## 服装模型预览

1. 在 Unreal Binding 中指定服装 **Preview Static Mesh**。
2. 在 Binding Actor 上点击 **刷新预览**，等待预览状态显示已就绪、有警告或失败。
   失败时会显示中文原因，连接状态独立显示；展开 **高级设置与诊断** 可查看并
   复制原始错误。Driver 角色的其他部分仍会显示。
3. 在 Maya 的 **连接** 页选择 **模型**，确认服装和 **传递 BS** 设置，再点顶部的
   **连接**。
4. 在 Maya 中给角色摆姿，检查 Unreal 中的服装变形。
5. 在 Binding Actor 的 **预览控制** 中点击 **显示原始服装**、**显示生成服装**，
   在相同姿势、Actor 变换、镜头和光照下比较；身体与启用的附加部件保持显示。
   此操作需要已就绪的 Generated Preview。按钮不可用时查看预览状态或悬停提示，
   按提示刷新或修正输入。失败或失效后显示“当前显示：原始角色”时仅供检查，不是
   模型对比结果。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| Maya 位于前台时 Unreal 会继续更新吗？ | 连接期间 Unreal 会保持后台编辑器与视口更新，可以保持 **Use Less CPU when in Background** 开启。断开后恢复原有后台行为，偏好和视口 Realtime 设置保持原值。编辑器最小化时不会绘制视口。 |
| Maya 提示 MtoU_LiveLink 安装不完整 | 提示中写明了缺少的文件。重新完整解压 Maya 组件，把其中的 `install.mel` 拖入 Maya 视口，然后重启 Maya。 |
| 安装后点击 MtoU 仍打开旧版本 | 安装时当前 Maya 已加载旧版本，重启 Maya 即可。 |
| Maya 提示“连接失败 · 插件协议版本不匹配” | 打开 **诊断** > **完整诊断**，或在启用弹窗时直接查看提示，可见 Maya 和 UE 实际加载的版本。对端未提供的值，在完整诊断中显示“—”，弹窗中显示“未知（对端未提供）”。请从同一发行包重新安装两端组件，重启 Maya 和 UE 后再连接。若 Maya 只显示旧提示“Maya 与 UE 插件版本不匹配”，说明 Maya 端组件较旧：请在 UE 的 Output Log 中搜索 “another protocol version”，其中一条警告写明了两端的插件版本与协议版本。 |
| 骨架不匹配 | 先按详情中的根因排查：首个未映射骨骼的完整路径与父级、受阻的 Maya 后代与未访问的 Unreal 骨骼数量，以及提示的导入改名候选；若详情指出同一必要骨骼由两根 Maya 骨骼竞争，请在 Maya 中重命名其中一根。再检查 Maya 选择的根骨骼、层级，以及 Unreal Driver 网格是否为最新版本。 |
| 附加部件被拒绝 | 诊断信息会指出具体部件和原因。请检查是否共用同一个 **Skeleton** 资产、Maya 中提示的必要骨骼及父链是否完整，以及共有参考姿势是否一致。若无法读取蒙皮权重，保留 CPU 蒙皮数据后重新构建或导入网格。 |
| 预览刷新失败 | 检查网格对齐情况、服装与身体的材质槽是否分离，修正提示的问题后重新刷新。 |
| 有意减面的模型无法通过自动服装识别 | 检查源模型是否有重复几何体或服装／身体混用材质槽。确认是有意减面后，在 Binding 的 **Driver Garment Slot Override** 中指定服装独立的材质槽，再刷新并检查效果。 |
| BlendShape 未生效 | 检查 Maya **连接** 页的 **传递 BS**、名称是否匹配、当前服装，以及 **诊断** 页里的结果。模型预览的源资产变更后需重新刷新。 |
| 镜头联动中经常显示“Maya 跟不上”和滞后时间 | 在 Maya 中打开 **窗口 > 设置/首选项 > 插件管理器**（英文界面：**Windows > Settings/Preferences > Plug-in Manager**），取消不用的插件的 **自动加载**，例如 MASH、XGen（`xgenToolkit`）、GPU Cache、Scene Assembly、LookdevX 和 Type，然后重启 Maya。打开场景时，场景需要的插件仍会加载。 |
| 修改后连接停止 | 同一主体的输入变化通常会自动重新协商，失败时查看停止原因。模型需要就绪的 Preview：修改或重导入相关输入后先刷新，再点击“连接”。显式刷新、主体更换、手动断开和失败均需明确“连接”，之后编辑不会恢复它们。见[连接期间的修改](#连接期间的修改)。 |

预览时请保留参与连接的 Binding Actor 并保持其关卡加载；删除该 Actor 或卸载其
关卡会停止连接。放置、刷新或删除没有参与连接的 Binding Actor 不改变已连接目标；
新协商不会用另一个 Actor 代替已被更换或移除的目标。
